# Передача: подарки прошли живой прогон, следующий — discount_percent в бою

## Сделано и проверено

- Девять сценариев (5 из `HANDOFF-clean-chat-and-gifts.md` + 4 подарочных)
  пройдены вживую на `@astrology_aid_dev_bot` с двух аккаунтов
  (`aid_kara` дарит, `astrid_team` забирает). «Второй день» имитирован
  сдвигом `users.last_active_date` и сбросом ключа `astra:activity:*` в Redis.
- Починена кнопка «Открыть подарок»: экран правится на месте только с кнопки
  на нём самом (`telegram/screen.py::_is_tap_on`), иначе переезжает вниз.
- Бесплатные (100% скидка) разборы дарятся: витрина без фильтра, подпись
  «бесплатно», на счёт другу — цена со скидкой (`services/gift_service.py`).
- Коммит `de1b458`. 1419 тестов с живой базой зелёные; pyflakes по тронутым
  файлам чист.
- Замечено по ходу: подарок «забирается» в конце регистрации (звёзды на счёт),
  а не по кнопке — так задумано; «Мои подарки» показывает только `issued`.

## Не доделано

- Старые баллы: `points_daily_visit` капает дальше, «⭐ N баллов» висит в
  «Обо мне». Записано кандидатом в «Не в плане» roadmap — решение за автором.
- Тесты кошелька/подарков скипаются молча, если `DATABASE_URL` не в
  окружении: `.env` не подхватывается pytest'ом. Гонять как
  `set -a; source .env; set +a; uv run pytest -q`. Не чинил — вне этапа.
