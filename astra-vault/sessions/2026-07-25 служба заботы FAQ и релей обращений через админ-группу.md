# Служба заботы: FAQ-самопомощь и релей обращений через админ-группу

Спроектировали и собрали **v1 поддержки в боте** с нуля (не опираясь на
старый код), ориентир — лучшие практики. Коммит `850c23a` на `main`.

## Решения (развилки, снятые с пользователем)

- **Архитектура — гибрид:** вход на виду → FAQ-самопомощь → релей к живому
  человеку. См. [[служба заботы гибрид FAQ и релей через админ-группу]].
- **Релей — через закрытую админ-группу** (не ЛС оператору, не уход в
  внешний аккаунт): бот кладёт карточку обращения в группу, оператор
  отвечает **reply** — бот доставляет ответ клиенту в бот.
- **AI-триаж — отложен на фазу 2.** Найдено: AI-чат Астрид полностью
  выключен (роутер не подключён в `bot.py`). Осознанно v1 без AI: FAQ
  детерминированы, нет риска, что LLM наврёт про возврат звёзд. AI к теме
  денег/возвратов не подпускаем в принципе.
- **Нейминг:** живая поддержка = «Служба заботы Astrid», убрали коллизию
  с AI-персоной «Астрид» (обе кнопки раньше были «Написать Астрид»).

## Что реализовано

- Вход: кнопка **«💬 Помощь»** в главном меню + `/help` + `/paysupport`
  (сразу ветка оплаты) + контекстное «Нужна помощь?» на orphan-платеже.
- Хаб + FAQ: оплата/возврат ⭐, вопрос по раскладу, профиль/город,
  уведомления. Тексты — `src/astra/telegram/support_text.py`.
- Релей: `handlers/support.py` (хаб/FAQ/вход), `handlers/support_relay.py`
  (приём обращения → карточка в группу; ответ оператора → клиенту).
- Карточка обращения включает **последнюю покупку с `charge_id`** — чтобы
  оператор сразу мог вернуть звёзды (см.
  возврат Stars через `refundStarPayment` по `charge_id` — если заметка есть).
- Пакет `astra/support/` (модель `SupportTicket`, crud, service).
- Миграция **018** `support_tickets` (up/down проверены на dev, `alembic
  check` — дрейфа по этой таблице нет).
- Служебная **`/chatid`** для получения ID группы (сторонние ID-боты
  отваливаются). Не в меню, работает по вводу текста, в т.ч. в группе.
- Удалён `help_text.py` (старая карточка с коллизией имени).
- 531 тест зелёный (`tests/test_support_service.py` — 14 новых).

- `.env`: `TELEGRAM_SUPPORT_USERNAME=astrid_team`,
  `TELEGRAM_ADMIN_GROUP_ID=-1004419830379` (**супергруппа**, ID стабилен).
- Проверено вживую через Bot API: `getChat` OK, тестовая карточка
  доставлена в группу (leg «бот → группа» работает). Обратная нога
  (reply оператора → клиенту) — только после деплоя нового кода.
