# Раздел «Спроси Астрид» и первый платный вопрос про судьбоносных партнёров

Спроектировали и собрали новый раздел бота — готовые вопросы к своей натальной
карте — и довели до конца первый платный продукт внутри него. Коммиты `f90b196`
(раздел) и `c5523bb` (продукт) на `main`.

Отправная точка — скриншот конкурента: меню тем в AI-чате. Разобрали, чем он
слаб (категории вместо вопросов, клик вслепую, ответ уровня гороскопа из
паблика) и что даёт нам перевес: астрологию считает Python, поэтому под каждый
вопрос можно подобрать свои факторы карты и заставить Астрид назвать их вслух.

## Решения (развилки, снятые с пользователем)

- **Название кнопки — «✨ Спроси Астрид»**, в главном меню вторым рядом под
  колесом. «Частые вопросы»/FAQ не использовать: так называется Служба заботы.
- **Структура — тема → вопросы**, восемь тем, навигация инлайновая.
  См. [[раздел Спроси Астрид два уровня и товар на каждый вопрос]].
- **Формулировки кнопок — кликбейтные вопросы со знаком «?»**, от первого лица.
  Слово «судьбоносный» утверждено (продаёт), но в промпте оговорено: это про
  сильного, поворотного человека, а не про предопределённость.
- **Цена — 1 ⭐** на вопрос, правится в БД.
- **Продукт «Сколько судьбоносных партнёров»:** два числа (было / впереди),
  все четыре блока разбора, драматургия подачи, карточка с числом, шаринг с
  реф-ссылкой, архив бесплатно + платный апдейт «что изменилось» (позже).
  См. [[сколько судьбоносных партнёров считает Python а объясняет LLM]].
- **Числа считает Python, LLM объясняет** — принцип всего раздела, вынесен в
  шаблон: [[продукт раздела Спроси Астрид собирается по одному шаблону]].

## Что реализовано

- Раздел: 8 тем, 12 вопросов в «Любви», род из профиля в подписях кнопок,
  «✍️ У меня свой вопрос», заглушки для ненаполненных тем.
- Расчёт: `ask/fated_partners.py` + `ask/windows.py` (транзитные окна через
  `swisseph`, Moshier — без файлов эфемерид). 0.02 с на карту.
- Пайплайн: черновик → инвойс → оплата → синхронный расчёт → карточка сразу →
  RabbitMQ → worker пишет разбор через DeepSeek → доставка. Авто-refund при
  фейле LLM (три попытки, валидация ответа).
- Карточка PNG 1080×1350 (Pillow), без личных данных — её пересылают.
- Миграция 019: `ask_readings`, товар `ask_love_fated_count` за 1 ⭐.
- 578 тестов зелёные (36 новых по разделу и продукту).

## Что осталось

- **Миграция и E2E на проде:** `alembic upgrade head` (019) → живая покупка →
  карточка → разбор → шаринг → архив.
- Наполнить остальные 7 тем вопросами и привести их к стилю с «?».
- Платный апдейт «что изменилось сейчас» по транзитам.
- Тюнинг: ближайшее окно для «впереди» иногда далеко (Юпитер ходит раз в 12
  лет) — рассмотреть окна среднего веса как подсказку по срокам, не меняя чисел.
