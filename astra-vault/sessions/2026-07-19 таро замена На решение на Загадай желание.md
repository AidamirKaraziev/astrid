# 2026-07-19 — Таро: «На решение» → «Загадай желание» (3 карты + вердикт + срок)

Заменили самый сухой тарочный продукт («Расклад на решение», Да/Нет) на более
попадающий в ЦА «Загадай желание». Заодно провели чистку общего кода раскладов.

## Решение по продукту

Из 5 предложенных концептов замены (Два пути / Вернётся ли / Что тебя ждёт /
Какая ты / Загадай желание) выбран **«Загадай желание»**, вариант 2 —
**компактный ритуал на 3 карты + явный вердикт**, с добавлением по просьбе
**срока «когда сбудется»**.

Срок — принципиально **честный диапазон** (дни/недели/месяцы/сезон), выведенный
из энергии расклада, без выдуманной точной даты. Если желание не складывается —
срок так и говорит («срок пока не читается»). Тон — как в «Отношениях»: по
картам, без сглаживания, без фатализма.

## Схема продукта (`wish.py`)

`verdict · timing · intro · heart · path · outcome · summary`, 3 позиции:
💫 Сердце желания → 🛤 Что на пути → 🌙 К чему идёт. Плюс строка ⏳ Когда сбудется
и вердикт-итог ✨.

## Что сделано

**Замена `yes_no` → `wish` (11 точек, без миграции — `spread_type` это `String(32)`,
таро не в проде):**
- `spreads.py`: `SpreadType.YES_NO` → `WISH`, новый spec на 3 карты.
- `yes_no.py` удалён → `wish.py`: схема, англ. `_METHOD` (`VALUES IN RUSSIAN`),
  честный вердикт + срок, кастомный рендер.
- Реестр `__init__.py`; кнопка `🌟 Загадай желание` + **legacy-роут** старой
  `⚖️ На решение` (`BTN_TAROT_DECISION_LEGACY`) на новый продукт — для
  закэшированных клавиатур (приём как с `BTN_ASK_ASTRID_LEGACY`).
- `keyboards.py`, хендлер (`start_wish`, `SPREAD_BUTTONS`), AI-чат
  (`Intent.tarot_wish` + промпт + диспатч).

**Чистка общего кода (санкционирована пользователем):**
- Вынес в `base.py` общий рендер **`render_with_intro()` / `intro_position_lines()`** —
  «Три карты» и «Отношения» больше не дублируют тело рендера.
- Вынес вердикт-хелперы **`normalize_verdict()` / `verdict_summary_block(label=…)`**
  (переиспользованы «Желанием»).
- Удалён мёртвый `render_positioned()`.

**Тесты:** `TestYesNo`→`TestWish` (+ честность/срок), роутинг, FSM (3 карты,
legacy-маппинг), сервис (фикстуры/caption). **Весь набор: 408 passed.**

## Осталось

- **Живой прогон** `make worker` → «🌟 Загадай желание» в реальном Telegram.
- Таро-трек по-прежнему **не запушен** на `origin/main`.
- Открытый вопрос (тянется): `reversed` в LLM не передаётся (`base.py::_cards_payload`).
