## Утверждённый план (полный цикл)

См. [[пайплайн совместимости промпт LLM PDF worker]].

Кратко:

1. **UX** — FSM партнёра, заказ в БД, (позже) Stars
2. **Astro** — Kerykeion `SynastryAspects` natal×natal, ранжирование орбов
3. **Промпт** — шаблон + JSON-схема ответа → [[промпт совместимости синастрия JSON для LLM]]
4. **LLM** — облачная модель (качество), parse → Pydantic
5. **Mapper** — LLM JSON + astro → `SynastryReportData`
6. **Worker** — generate PDF → `sendDocument`

### Порядок PR (утверждено в сессии)
