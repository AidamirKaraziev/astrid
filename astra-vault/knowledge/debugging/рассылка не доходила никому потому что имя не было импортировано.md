# Рассылка не доходила никому, потому что имя не было импортировано

## Симптом

Рассылка из админки уходит, в истории у каждого получателя «не дошло».
Бот при этом жив, остальные разделы работают.

## Причина

`src/astra/workers/handlers.py:473` вызывал `send_telegram_html`, но в
модуле этого имени не было: импортировался только
`send_prediction_to_telegram` из того же `astra.workers.telegram_send`.
Проверяется в одну строку:

```python
hasattr(astra.workers.handlers, "send_telegram_html")  # False
```

Внёс `b0a137d feat(рассылки)` от 29 июля. Рассылка не работала ни разу с
того дня — в базе `broadcasts` остался только черновик, поэтому никто не
заметил.

## Почему это выглядело не как падение

`broadcasts/service.py:159` ловит **любое** исключение замыкания и пишет
его в `delivery.error`:

```python
except Exception as exc:  # noqa: BLE001 — причину показываем в истории
    delivery.error = f"{type(exc).__name__}: {exc}"[:200]
```

Поэтому `NameError` не рвал рассылку, а аккуратно складывался в историю у
каждого получателя. Снаружи — тихий ноль доставок вместо громкой ошибки.
Решение «показывать причину в истории» само по себе верное; плохо, что в
историю никто не смотрел.

## Почему тест был зелёным

`tests/test_broadcast_sending.py` проверяет `send_all` с
`sender = AsyncMock()` — и делает это правильно: его слой, цикл по
получателям, работает. Настоящее замыкание `sender`, которое зовёт
отсутствующую функцию, живёт внутри `handle_broadcast_send` и тестами не
было покрыто вовсе. Непокрытый слой — не «мало тестов», а точное место,
где живут такие баги.

## Почему линтер не поймал

`ruff` с набором `F82` ловит неопределённые имена и поймал бы это с
первого дня. Поймать помешала заглушка, поставленная **ради зелёного
линтера** при его внедрении:

```toml
[tool.ruff.lint.per-file-ignores]
"src/astra/workers/handlers.py" = ["F821"]
```

Заглушку поставил работник по моей же инструкции «сделать зелёным
настройкой, код не правим». Инструкция была неверной: она снимала не
симптом, а сигнал. Заглушка `per-file-ignores` на класс ошибок-багов (не
стиля) — это отложенная авария, и ставить её можно только вместе с
задачей, которая её снимает.
