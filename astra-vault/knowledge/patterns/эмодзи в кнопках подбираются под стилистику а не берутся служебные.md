# Эмодзи в кнопках подбираются под стилистику, а не берутся служебные

Astra — бот про астрологию, и его интерфейс собран из мягких «астральных»
эмодзи. Служебные значки из панелей управления (перемотка, шестерёнки,
стрелки-циклы) в этот ряд не встают и сразу читаются как техническая заглушка.

**Правило: к каждой новой кнопке эмодзи подбирается осознанно, под смысл и
стилистику. Первый попавшийся «логичный» значок — не годится.**

## Палитра, которая уже сложилась

| Смысл | Эмодзи |
|---|---|
| раздел, магия, «составить» | ✨ |
| карты, таро, предсказание | 🔮 🃏 |
| поделиться, лёгкость | 💫 |
| повтор, ещё круг | 🌀 |
| любовь, отношения | ❤️ 💕 |
| забота, тепло от бота | 💜 |
| натальная карта, космос | 🌌 |
| приз, подарок | 🎁 |
| колесо фортуны | 🎡 |
| написать текстом | ✍️ |
| архив, готовый ответ | 📖 |
| время, сроки | 🕐 📅 |
| назад | 🔙 |

## Примеры замен

| Служебное | Стильное | Почему |
|---|---|---|
| 🔁 Сделать разбор заново | **🌀** | 🔁 — перемотка трека; спираль читается как «ещё круг» и остаётся в астральном ряду |
| ⚙️ Настройки | ✨ / 👤 | шестерёнка — из панели администратора, не из разговора с Астрид |
| ✅ Готово | ✨ / 💜 | галочка уместна только в чек-листе действий внутри ответа |
| ➡️ Далее | 🔙 (пара к «Назад») | стрелки из браузера ломают ряд |

## Как проверять

1. Поставить новую кнопку рядом с соседними в том же экране и посмотреть на
   ряд целиком: выбивается — менять.
2. Не занимать эмодзи, который уже закреплён за другим смыслом (🔮 — карты,
   💫 — поделиться): иначе человек читает кнопку неправильно.
3. Эмодзи один и в начале подписи. Два подряд и эмодзи в конце — не наш стиль.
