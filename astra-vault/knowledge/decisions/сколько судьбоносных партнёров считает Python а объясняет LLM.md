# «Сколько судьбоносных партнёров» считает Python, а объясняет LLM

Первый платный продукт раздела «✨ Спроси Астрид». Отдаёт **два числа**:
сколько судьбоносных союзов уже было и сколько впереди.

Судьбоносный = поворотный союз, после которого человек другой. **Брак не
обязателен** — считаем истории, а не штампы.

## Решение

Числа считает `src/astra/ask/fated_partners.py`, LLM получает их готовыми и
только объясняет. Модель не пересчитывает, не спорит и не добавляет своих —
в схеме ответа нет числовых полей вовсе.

## Метод

**Сколько всего за жизнь** — счёт по факторам:

| Фактор | Куда двигает |
|--------|--------------|
| модальность знака на десценденте | фиксированный −1, мутабельный +1 |
| двойной знак на DSC (Близнецы/Стрелец/Рыбы) | +0.5 |
| личные планеты в 7 доме | +0.3 / +0.6 / +1.0 |
| управитель 7 дома: знак | мутабельный +0.5, фиксированный −0.5 |
| аспекты управителя и Венеры с Сатурном / Ураном / Юпитером | −0.7 / +0.6 / +0.3 |
| Венера ретроградная | +0.3 (истории возвращаются) |
| северный узел в 7 / в 1 доме | +0.3 / +0.2 |

Счёт → число по порогам (−0.9 / 0.5 / 1.8 → 1 / 2 / 3 / 4). Пороги подобраны
по квантилям счёта на выборке из 300 случайных карт: целились в распределение
15/35/30/15, получили 17/35/31/17.

**Прошлое и будущее** — окна активации партнёрства (`ask/windows.py`):
транзиты Сатурна, Юпитера и Урана к десценденту, Венере и управителю 7 дома.
Помесячный скан через `swisseph` (`FLG_MOSEPH`, файлы эфемерид не нужны),
орбис 3°, соседние месяцы схлопываются в окно, пересечения в пределах года —
одна история, а не две. Считаем от 16 лет и на 15 лет вперёд. Расчёт — 0.02 с.

**Деление** — по доле прожитых окон, не по их количеству. Это ключевая
калибровка: при делении «сколько окон прошло» у человека за сорок всё всегда
оказывается позади и вопрос «сколько впереди» теряет смысл.

**Ещё две калибровки:**
- потолок «уже было» по возрасту: до 22 — одна, до 28 — две, до 35 — три;
- ответ человека «сейчас в отношениях или нет» (один вопрос перед покупкой):
  в отношениях → минимум одна история уже позади; свободен и есть открытое
  окно → одну историю переносим из прошлого в будущее, общее число не раздуваем.

Сколько партнёров уже было — **не спрашиваем никогда**. Угадывание прошлого и
есть эффект, за который платят.

## Чего сознательно нет

- **Юноны и Даракараки.** Астероиды недоступны в Moshier-эфемеридах, а
  Даракарака — вообще джйотиш: мешать две системы в одном продукте нельзя.
- **Точных дат.** Только периоды и возраст: «ближе к 42», а не «14 марта».
- **Обещаний загса.** В промпте прямой запрет на «единственного, кого послала
  судьба» и любую предопределённость.

## Проверено живьём

Карта 15.03.1990, 14:30, Москва → 2 партнёра (1 был, 1 впереди). DeepSeek
назвал факторы вслух: «В 31 год Сатурн шёл по твоему десценденту — классическое
время для судьбоносного партнёра», маркеры узнавания конкретные, Barnum-фраз нет.
