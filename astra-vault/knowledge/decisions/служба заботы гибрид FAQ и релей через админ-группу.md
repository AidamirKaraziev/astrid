# Служба заботы: гибрид FAQ + релей через админ-группу

## Решение

Поддержка в боте построена как **гибрид из трёх слоёв**:

1. **Вход везде на виду** — кнопка «💬 Помощь» в главном reply-меню,
   команды `/help` и `/paysupport`, контекстное «Нужна помощь?» в точках
   сбоя (orphan-платёж). Рассчитано на пользователя, который слабо
   владеет телефоном: не прячем помощь в Menu Button.
2. **FAQ-самопомощь** — хаб с готовыми ответами по темам
   (оплата/возврат ⭐, расклад, профиль/город, уведомления). Закрывает
   типовое без человека.
3. **Релей к живому оператору через закрытую админ-группу** — клиент
   пишет в боте, бот кладёт карточку обращения в группу; оператор
   отвечает **reply** на карточку, бот доставляет ответ клиенту в бот.
   Клиент не покидает бота.

## Почему так

- **Админ-группа, а не ЛС оператору:** вся история в одном месте, легко
  добавить операторов, надёжный маппинг «карточка → клиент» по
  `reply_to_message.message_id`. Ответы-reply приходят боту даже при
  включённом privacy mode (это ответ на сообщение самого бота).
- **Карточка с `charge_id` последней покупки:** оператор сразу видит
  контекст и может вернуть звёзды без переписки.
- **Без AI в v1 (осознанно):** AI-чат Астрид на тот момент выключен
  (роутер не подключён). FAQ детерминированы — нет риска, что LLM наврёт
  про возврат денег. AI к теме денег/возвратов не подпускаем в принципе.
  AI-триаж первой линией — фаза 2.
- **Нейминг «Служба заботы»:** снимает коллизию с AI-персоной «Астрид»
  (раньше и AI-чат, и человек были «Написать Астрид»).

## Ключевые детали реализации

- Стабильность ID группы: нужна **супергруппа** (`-100…`). Обычная группа
  при апгрейде меняет ID → релей молча ломается.
- `SupportStates.writing` добавлен в suppressed-состояния
  `keyboard_policy`, чтобы в режиме написания держалась своя
  «Назад»-клавиатура, а не главное меню.
- Роутеры: `support` — после `navigation` (кнопки меню прерывают FSM),
  `support_relay` — последним (ловит свободный текст в своём состоянии и
  reply-сообщения в админ-группе, не мешая продуктовым флоу).
- Fallback: если `TELEGRAM_ADMIN_GROUP_ID=0`, кнопка «написать» ведёт в
  личный аккаунт `@astrid_team` (мягкая деградация).
