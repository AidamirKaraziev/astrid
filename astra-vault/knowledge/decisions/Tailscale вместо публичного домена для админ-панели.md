# Tailscale вместо публичного домена для админ-панели

Панель `/admin` доступна снаружи через Tailscale по адресу
`http://100.120.8.76:8000/admin`. Cloudflare Tunnel рассматривали и отклонили.

## Почему

- панель нужна **одному человеку** и открывается редко: выставлять её в
  интернет ради этого — лишняя поверхность атаки;
- снаружи не видно вообще ничего: нечего сканировать, нечего перебирать, и
  локаут после десяти попыток становится страховкой, а не единственной защитой;
- домен не нужен, в репозитории ничего не меняется;
- mihomo на deadtiger работает обычным SOCKS-прокси (`mixed-port`), а не в
  TUN-режиме, поэтому интерфейс Tailscale не дерётся с ним за маршруты и
  Telegram у бота не отваливается.

Публичного IP у сервера нет — оба варианта работают наружу исходящим
соединением, статический адрес не нужен ни одному.

## Цена решения

На телефоне одновременно работает только один VPN: если включён VPN для
Telegram, для входа в панель придётся переключиться.

## Когда вернёмся к Cloudflare

Когда подключим оплату картами прямой интеграцией: провайдеру нужен публичный
HTTPS под вебхук. Тогда наружу через туннель пускаем **только вебхук и
юридические страницы**, а панель оставляем в тайнете.

## Известная мелочь

Имя `deadtiger` с макбука не резолвится: системный резолвер macOS не знает ни
одного имени в `ts.net`, хотя `dig @100.100.100.100` отвечает верно — DNS
перехватывает один из VPN-клиентов. Заходим по IP, он закреплён навсегда.
