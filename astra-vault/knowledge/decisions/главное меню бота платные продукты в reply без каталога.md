# Главное меню бота: платные продукты в reply, без каталога

## Решение

Платные продукты — **сразу в главном reply-меню** (2 кнопки в ряд). Отдельный экран «Каталог» убран.

Помощь — **только** `/help` (Menu Button), не reply-кнопка.

**🌟 Спросить звёзды** — только **inline** под ежедневным прогнозом (upsell), не в reply.

## Раскладка

```
[ 🔮 Предсказание на сегодня ]
[ 💕 Совместимость ] [ 🌌 Разбор натала ]
[ 📅 Прогноз на месяц ] [ 🔮 Карты Таро ]
[ ✨ Обо мне ] [ 🎁 Пригласить друга ]
```

Таро → подменю с раскладами.

## Menu Button

Только `/start` (🏠 Главное меню) и `/help` (💌 Написать Astrid). `/menu` — алиас `/start`.

## Почему

- Меньше кликов до платного продукта.
- Menu Button не перегружен дублями reply-кнопок.
- Reply = ежедневный habit; Menu = старт и поддержка.

## Статус продуктов

Заглушки до P3 монетизации. Цены — из [[портфель монетизации Astra]].
