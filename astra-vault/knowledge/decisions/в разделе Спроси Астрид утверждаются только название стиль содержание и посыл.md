# В разделе «Спроси Астрид» утверждаются только название, стиль, содержание и посыл

Правило работы над новыми кнопками и вопросами раздела. Оно про то, **что
спрашивать у пользователя, а что уже решено** и переспрашиванию не подлежит.

## Спрашиваем (и только это)

| Что | Как подавать |
|-----|--------------|
| **Название** | 3–4 варианта, рекомендация первой, коротко почему |
| **Стиль** | формулировки кнопок: вопросы со знаком «?», от первого лица, кликбейтно — показать готовый список, не спрашивать «какой тон?» |
| **Содержание** | какие вопросы внутри темы / какие блоки внутри ответа — списком, пронумерованным, чтобы утвердить или назвать номера на правку |
| **Посыл** | что человек должен вынести из ответа: обещание, честность, куда ведём дальше |

Всё подаётся готовым к ответу «утверждаю» одним словом. Варианты — списком с
номерами и буквами (1A, 2B…), чтобы правки назывались коротко.

## Не спрашиваем — решено раз и навсегда

- **Числа и факты считает Python, LLM объясняет.** Схема ответа без числовых полей.
- **Цена** — товар на вопрос, `product_prices`, правится в БД. Не обсуждаем на
  каждом вопросе.
- **Навигация инлайновая**, тема → вопросы → ответ.
- **Флоу покупки:** архив бесплатно → предложить вписать время рождения (не
  запирать) → один калибрующий вопрос → инвойс → расчёт синхронно → карточка
  сразу → разбор из worker → авто-refund при фейле.
- **Скидка 100%** — выдаём без инвойса.
- **Пороги** подбираются по распределению на выборке карт, а не на глаз.
- **Калибровки:** потолок прошлого по возрасту, деление по доле прожитых окон,
  статус спрашиваем — прошлое никогда.
- **Без времени рождения** отвечаем, дома не упоминаем, в конце честная приписка.
- **Вопросы про конкретного человека** — не в раздел, а кросс-продажа в
  «💕 Совместимость».
- **Промпт в коде — на английском** (утверждаем по-русски, кладём перевод).
- **Тон Астрид:** тепло, на «ты», без фатализма, без Barnum-фраз, факторы карты
  названы вслух.

Всё остальное — техника: делать по [[продукт раздела Спроси Астрид собирается по одному шаблону]],
не выносить на обсуждение.

## Если возникла неоднозначность

Не блокировать вопросом. Сделать по шаблону, коротко назвать принятое допущение
в конце ответа — пользователь поправит, если что.
