# GeoNames — справочник населённых пунктов СНГ

Бесплатные данные: https://www.geonames.org/ (лицензия CC BY 4.0).

Пятнадцать постсоветских стран: RU, UA, BY, KZ, UZ, KG, TJ, TM, AZ, AM, GE,
MD, LV, LT, EE. Около 337 тысяч населённых пунктов, включая хутора и
упразднённые сёла. Фермы, урочища и микрорайоны не берём осознанно —
почему, написано в докстринге `astra/places/geonames_import.py`.

## Автозагрузка

При старте API, если таблица `places` пуста, приложение само скачивает дампы
и импортирует данные. Отключить: `GEONAMES_AUTO_IMPORT=false`.

## Ручной переимпорт

```bash
uv run alembic upgrade head
uv run python scripts/import_geonames.py
```

Повторный запуск **обновляет** записи по `geoname_id`, а не пересоздаёт их:
`places.id` лежит в `profiles.birth_place_id`, и пересоздание строк стёрло бы
людям место рождения вместе с натальными картами.

## Названия

Русское имя берётся из `alternateNamesV2.txt` — там у каждого варианта есть
язык и признаки «предпочтительное», «краткое», «разговорное», «историческое».
Ленинград, Молотов и Питер основным именем стать не могут.

До этого имя брали из общей свалки синонимов без языковых меток, и в
справочнике жили «Бетъырбух» вместо Санкт-Петербурга и «Буро-ГӀала» вместо
Владикавказа.

У четверти мест русского названия в источнике нет вовсе — они остаются
латиницей (`Zyabrikovo`). Придумывать написание нельзя: это место рождения
человека. Находятся такие места по русскому запросу через транслитерацию.
